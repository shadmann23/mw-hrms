System Roles Explained

HR Administrator
  • Full access to all modules
  • Create & deactivate employees
  • Approve all leave requests (L2)
  • Post company-wide notices
  • Resolve support tickets
  • Access System Admin panel
  • Manage roles & departments
  • Fire or terminate employees
Supervisor
  • View team members' profiles
  • Approve team leave requests (L1)
  • Assign shifts to team members
  • View team attendance report
  • Create and manage teams
  • View notices (all + supervisors)
  • Submit own leave requests
Employee
  • View own profile only
  • Check in / check out
  • Submit leave requests
  • View own attendance history
  • View shift calendar (own)
  • View notices (all + employees)
  • Submit support tickets
